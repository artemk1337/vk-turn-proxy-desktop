# Changelog

## v1.1.0 - 2026-11-14

- **Feature**
  - Профили Windows - сохранение, переключение и отдельное окно настройки.
  - VK - общая учётная запись и периодическая проверка сессии.
- **Bugfix**
  - Вход в VK - исправлено открытие окна авторизации.
  - Тёмная тема Windows - исправлены оформление окон профилей и видимость поля лимита журнала.
  - Кнопки Windows - локализованные подписи помещаются в компактном интерфейсе.
- **Improvement**
  - Интерфейс Windows - компактный главный экран, переключатель темы и этапы подключения.
  - Журнал Windows - настраиваемый лимит строк, по умолчанию 1000, с ограничением памяти.

## v1.0.2 - 2026-11-14

- **Bugfix**
  - Вкладки Windows - устранено дрожание текста при наведении.
  - Автозапуск Windows - исправлено выравнивание флажка в настройках.
- **Improvement**
  - Интерфейс Windows - компактное окно, поля языка и темы, аккуратные отступы.

## v1.0.1 - 2026-11-14

Первый релиз.

- **Feature**
  - Windows и Linux - графический и терминальный клиенты.
  - Подключение по ссылке профиля или WireGuard-конфигу, вход в VK.
  - Установщики и переносимые версии для x64 и ARM64.
