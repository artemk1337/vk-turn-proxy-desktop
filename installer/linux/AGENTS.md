# Linux packages

Follow the root [AGENTS.md](../../AGENTS.md).

- `package.sh` assembles amd64/arm64 portable archives and Debian packages from locally built Wails GUI and console binaries. The shared frontend and fonts are embedded in the GUI.
- Keep the GUI unprivileged. The console requests administrator access through pkexec only when connecting.
- Install application files under `/usr/lib/vk-turn-proxy-desktop`, launchers under `/usr/bin`, and desktop metadata under `/usr/share`.
- Never ship user profiles, cookies, generated bytecode or tests in application packages.
- Package removal preserves user preferences and network recovery state. User autostart entries use TryExec so missing launchers are skipped.
- Run `smoke.sh <native.deb> <capture-directory>` in a disposable Debian/Ubuntu environment as root. It checks an unprivileged GUI session and package removal.

- Build the Linux GUI with CGO, GTK 3 and WebKitGTK 4.1 using `-tags desktop,production,webkit2_41`. The optional Python WebKit login helper is embedded in the executable.
